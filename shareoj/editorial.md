## 解説

### 最小最大ターン数の立式

問題文を以下のように言い換えます。

> 両者が最適な行動を取った際に、RUさんの手番時に、初めて$A=B$となるまでに経過したターン数を$V$とします。$V$が$K$未満であるか判別してください。

各$i$において、$(A_i, B_i)$の組み合わせの個数を以下のように表します。

- $z=\# (0, 0)$
- $a=\# (0, 1)$
- $b=\# (1, 0)$
- $o=\# (1, 1)$
- $m=a+b$

お互いにとって最適な行動は、不一致の個数$m$を減らす/維持することです。それが、RUさんの手番で$0$になった時に、ゲームは終了します。

$m$は、UDKさんが停止しているターンにのみ減少します。

よって、ゲーム中に、UDKさんが$1 \to 0$とする回数は$m$と一致します。

$u$をUDKさんがゲーム中に$0 \to 1$とする回数とするとき、$V = 2m + u$と評価できます。

### ターン最大化のためにUDKさんが取れる行動

以下の$3$つが、停止することなくUDKさんが手に入れられる、$u$に寄与する$(0, 0)$の発祥元です。

- もともとある$(0, 0)$: $z$個
- RUさんによって改変された元$(1, 0)$: $a$個
- 攻防の末に完成した$(0, 0)$: $m-1$個

これらの行動のいずれもRUさんが妨害できないとき、$u=z+a+m-1$となり、$V=3a+4b+z-1$となります。

そして、RUさんは、初手で夢想封印をする場合を除き、これらを妨害することはできません。最終的に、$(A, B)=(0, 0)(1,1)^{N-1}$となります。

## 1. 記号

追う側をRUさん（R）、逃げる側をUDKさん（U）とします。

状態はRUさんの手番開始時点で $s=(a,b,z,o;f)$ と書きます。

次の量を定義します。

$$E(s)=3a+4b+z-1$$

## 2. 操作と $E$ の変化

R の1手は次の5種類です。

| R の操作 | 状態の変化 | $\Delta E$ |
|---|---|---|
| 直す $(0,1)\to(1,1)$ | $a\to o$ | $-3$ |
| 直す $(1,0)\to(0,0)$ | $b\to z$ | $-3$ |
| 待つ | なし | $0$ |
| 崩す $(0,0)\to(1,0)$ | $z\to b$ | $+3$ |
| 崩す $(1,1)\to(0,1)$ | $o\to a$ | $+3$ |

U の1手は次の4種類です。U が動ける時は、必ず1回反転しなければなりません。

| U の操作 | 状態の変化 | 停止 | $\Delta E$ | 実効 |
|---|---|---|---|---|
| U1 $(0,0)\to(0,1)$ | $z\to a$ | なし | $+2$ | $+2$ |
| U2 $(1,1)\to(1,0)$ | $o\to b$ | あり | $+4$ | $+2$ |
| U3 $(0,1)\to(0,0)$ | $a\to z$ | あり | $-2$ | $-4$ |
| U4 $(1,0)\to(1,1)$ | $b\to o$ | なし | $-4$ | $-4$ |

「実効」は、停止すると次のターンで R が追加の1手を得る分（下の $\Phi_1$ の $-2$）を織り込んだ値です。

**要点：** R が1ターンで $E$ を下げられるのは $-3$ が上限で、U の最善の応手は実効 $+2$ です。差し引き $-1$ ずつ進むことになります。

## 3. ポテンシャル関数

$N\ge2$ とします。$N=1$ は後で別に扱います。$m\ge1$ のとき、

$$\Phi(s;0)=\begin{cases}E & z+o\ge1\\ E-3 & z+o=0\ (\text{全て不一致})\end{cases}\qquad
\Phi(s;1)=\begin{cases}E-2 & m\ge2\\ 1 & m=1\end{cases}$$

$m=0$ のときは $\Phi=0$ とします。$m\ge1$ なら常に $\Phi\ge1$ です。

> **主張：** $V=\Phi(s_0;0)$（初期状態は $f=0$）。

## 4. 補題

### 補題1（$f=1$：U が動けない）

$\Phi(s;1)=1+\min_\kappa\Phi(s_\kappa;0)$ が成り立ちます。ここで $\kappa$ は R の手、$s_\kappa$ はその後の状態です。

- $m\ge2$ のとき、直す手で $E-3$ になります。待つ・崩すはそれ以上です。全て不一致の場合でも、待つと $E-3$ で直す手と同値です。したがって $\Phi_1=E-2$ です。
- $m=1$ のとき、直すと一致して $0$ になるので $\Phi_1=1$ です。

U の選択がないため、この補題は上界と下界を同時に与えます。

### 補題2（上界：R は $\Phi$ を毎ターン $1$ 以上下げられる）

$f=0$、$m\ge1$ とします。

**(i) $z+o\ge1$ のとき**、R は任意の不一致を直します。直した後の状態は $E_\kappa=E-3$ です。U の応手別に確認します。

- U1：$\Phi\le E_\kappa+2=E-1$。
- U2：$\Phi_1\le E_\kappa+4-2=E-1$。$m'=1$ のときは $\Phi_1=1$ ですが、$m=1$ なら $E\ge2$ なので $1\le E-1$ です。
- U3・U4：さらに小さくなります。
- 一致して $0$ になる場合も $0\le E-1$ です。

**(ii) $z+o=0$ のとき**（$\Phi=E-3$）、R は**待つ**。U は U3 か U4 しか選べません。

- U4：$E-4$。次の状態は $z+o=1$ なので一般形です。
- U3：$\Phi_1=E-2-2=E-4$。

どちらも $\Phi-1$ です。

### 補題3（下界：U の応手が存在する）

これが「3つの手段が妨害されずに実現可能」の証明です。

U の方針は次のとおりです。**無料で崩せる $(0,0)$ があれば U1、なければ U2。** 以下、R のどの手に対しても $\Phi(\text{次})\ge\Phi-1$ となり、かつ次の状態で $m\ge1$ であることを示します。

**ケース A：R が直す**

- 直した後に $(0,0)$ がある場合、U は U1 を選びます。直した結果の状態は $E-3$ なので、$E-3+2=E-1$ です。
  - 直したのが元 $(1,0)$ なら、U1 は**いま生まれた $(0,0)$ を即座に崩す**ことになります。これが手段②（元 $(1,0)$ を崩す）です。
  - 直したのが $(0,1)$ なら、すでにある $(0,0)$ を崩します。それが元からあるものなら手段①、過去に生まれたものなら手段③です。
- $(0,0)$ がなければ、U は U2 を選びます。停止の代わりに R が次のターンで $(1,0)\to(0,0)$ と直すと、新しい $(0,0)$ が生まれます。これが手段③の供給源です。$E-3+4-2=E-1$ です。
- 最後の不一致を直したとき、U2 の結果は $m'=1$ で $\Phi_1=1$ です。この場合 $E=2$ なので、$E-1=1$ と一致します。

**ケース B：R が待つ**

$z+o\ge1$ なら、U1 か U2 で $\ge E-1$ です。具体的には、U1 が最後の一致を消すと $E+2-3=E-1$ になります。U2 なら $E+2$ です。

**ケース C：R が一致を崩す**

$E$ が $+3$ になるので、U1/U2 で十分です。

特に、R が**唯一の一致を崩して**全て不一致にした場合は、U1/U2 が使えません。このとき $m_\kappa\ge2$ なので、U3 か U4 のどちらかは必ず使えます。結果はちょうど $E-1$ です。

- U4：$E+3-4=E-1$。
- U3：$\Phi_1=E+3-2-2=E-1$。

**ケース D：$z+o=0$（$\Phi=E-3$）**

- R が直すと、一致が1つできます。U はそれを崩して $E-4=\Phi-1$ です。
- R が待つと、U は U3/U4 を強制されて $E-4$ です。

以上で、R のどの手に対しても U に $\Phi(\text{次})\ge\Phi-1$ となる応手があり、その結果の $m$ は $\ge1$ です。

**ここまでの帰結。** R が一致する $E$ を減らせるのは $-3$ までで、U の実効 $+2$ を相殺しきれません。R が一致を崩す・待つといった「妨害」を試みても、$E$ は $+3$ や $0$ 増えるだけで、むしろ U に有利になります。つまり、3つの手段は R に妨害されません。

## 5. 定理

**定理。** $m\ge1$ のとき $V=\Phi(s_0;0)$。

**証明。**

- 補題2により、R は毎ターン $\Phi$ を $\ge1$ 減らせます。$m\ge1$ なら $\Phi\ge1$ なので、$\Phi$ ターン以内に $m=0$ になり、$V\le\Phi$ です。
- 補題1・3により、U は $\Phi$ を毎ターン $1$ より多くは減らさせません。一致時の $\Phi$ は $0$ なので、$V\ge\Phi$ です。
:::

### 「待つ」の有効活用

すべての組み合わせが不一致である($m=N$)ときに限り、RUさんにとって、「待つ」手が常に有効です。

- $a=N$のとき、UDKさんは $1\to0$ しか選べません。$(0,1)\to(0,0)$ となってUDKさんは停止します。
- それ以外の場合、$1$ターン消費で$(1,1)$ が1個増え、$(1,0)$ が1個減ります。

この盤面は、不一致数の遷移の単調性から、初期状態にしか起きえません。前処理として適用しましょう。

これらを組み合わせることにより、$O(\sum N)$の実行時間で判定することが出来ました。


:::details 提出例
```cpp
#include <bits/stdc++.h>
using namespace std;
#define ll long long

void won(bool win) {
  cout << (win ? "Yes" : "No") << '\n';
}

void solve() {
  int N, K; 
  cin>>N>>K;
  
  string A, B;
  cin>>A>>B;
  
  int cnt00=0, cnt01=0, cnt10=0, cnt11=0;
  
  for(int i=0; i<N; ++i) {
    if(A[i]=='0' && B[i]=='0') cnt00++;
    if(A[i]=='0' && B[i]=='1') cnt01++;
    if(A[i]=='1' && B[i]=='0') cnt10++;
    if(A[i]=='1' && B[i]=='1') cnt11++;
  }
  
  int rem=N-(cnt00+cnt11);
  
  if(rem==0) {
    won(true);
    return;
  }
  
  int sum=0;
  
  //「なにもしない」
  if(rem==N) {
    if(N==1) {
      won(K>1);
      return;
    }
    
    if(cnt01==rem) {
      //倍加RUさんで終焉
      if(rem==2) {
        won(K>2);
        return;
      }
      
      cnt00++, cnt11++;
      cnt01-=2;
      sum+=2;
    }
    else {
      cnt11++;
      cnt10--;
      sum++;
    } 
  }
  
  //ターンのminimax数
  sum+=2*cnt01 + 3*cnt10 + max(0, cnt01+cnt10-1) + (cnt01+cnt10>0 ? 1:0)*cnt00;
  won(sum<K);
}

int main() {
  int T; cin>>T;
  while(T-->0) solve();
}
```
