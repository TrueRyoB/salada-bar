## 問題文
[明星ロケット(mp3)](https://www.youtube.com/watch?v=0c2ilKlqW0Y)

> 二人は追いかけっこをします。

長さ$N$のバイナリ文字列 $A$ と $B$ が与えられます。

$1$ターン目から始まり、毎ターン、RUさんとUDKさんは交互に行動します。

RUさんは、以下の行動のうちいずれかを選びます。

- $A_i=0$ を満たす $i$ を選び、$A_i=1$ に変更する。
- $A_i=1$ を満たす $i$ を選び、$A_i=0$ に変更する。
- 何もしない。バイナリ列 $A$ と $B$ が完全に一致しているとき、UDKさんに追いつき、``霊符「夢想封印」``で**勝利**する。

その後、UDKさんは以下の行動のいずれかを選びます。

- $B_i=0$ を満たす$i$を選び、$B_i=1$ に変更する。
- $B_i=1$ を満たす$i$を選び、$B_i=0$ に変更する。この際、次のターンには**動けなくなる**。
- $K$ターン目以降に選択可能となる。（待つことができない。）``恋符「マスタースパーク」``により、RUさんの**敗北**となる。

両者が最適に行動したとき、RUさんは、このゲームに勝利することができるでしょうか？ $T$ 個のテストケースに対して、それぞれ求めてください。


## 制約
- $1 \leq T \leq 10^4$
- $1 \leq N \leq 10^5$
- $1 \leq K \leq 10^9$
- $A_i, B_i \in \{0, 1\}$
- 全テストケースにおける $N$ の総和は $10^{6}$ 以下

## 部分点

- $N \leq 10$を満たすデータセットに正解した場合は、部分点である$400$点が与えられます。

## 入力形式

```input
$T$
$\text{case}_1$
$\vdots$
$\text{case}_T$
```

各テストケース $\text{case}_t\ (1\leq t \leq T)$ は以下のように与えられます。
```input
$N$ $K$
$A$
$B$
```

## 出力形式

各テストケースに対して、`Yes` か `No` で、一行ずつ答えを出力してください。
